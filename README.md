# Loan Data Analysis Project

This project is a simple exploratory data analysis of a loan dataset using Python and Jupyter Notebook. It focuses on understanding the structure of the data, key loan attributes, and patterns in borrower and loan information without using machine learning models.

## Files
- `Loan_Data_Analysis_No_ML.ipynb` – main analysis notebook
- `loan.xlsx` – source dataset used in the project

## Objective
- Load and inspect the dataset
- Understand the available columns and data types
- Summarize loan-related statistics
- Explore the relationship between loan attributes and loan status

## Requirements
Install the following Python packages if needed:
- pandas
- numpy
- matplotlib
- seaborn
- openpyxl
- jupyter

## Run the notebook
1. Open the project folder.
2. Start Jupyter Notebook:
   ```bash
   jupyter notebook
   ```
3. Open `Loan_Data_Analysis_No_ML.ipynb` and run the cells.

This is a brief academic/data-analysis project for understanding loan data and extracting insights from raw financial records.
